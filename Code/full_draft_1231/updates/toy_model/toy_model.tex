\section{Timing and initial conditions}
Consumers arrive with observed initial state $a\in\{j,k,0\}$, each with probability $\mu_a=1/3$ independently of switching type. Initial state 0 has no switching reward. Both periods allow switching. Consumers choose myopically, and period-one outside choices exit permanently.

The firm freely sets transaction prices for both products in both periods. There are no coupons, maintained regular prices, or imposed price bounds. Period-one prices depend on $a$; period-two prices may depend on the full observed history $(a,h)$, where $h$ is the first purchase. Menus are committed before choices. Type probabilities are known initially, and the objective accounts for endogenous sorting of types into purchase histories. In particular, first purchases can now be informative about type.
\section{Consumer and producer problems}
For $\ell\in\{j,k\}$ and previous purchase $h$, deterministic utility is
\[
V_{r\ell t}(h)=\beta_\ell+\gamma_r\mathbf1\{h\ne0,\ell\ne h\}+\alpha p_{\ell t},
\qquad s_{r\ell t}=\frac{e^{V_{r\ell t}}}{1+\sum_m e^{V_{rmt}}}.
\]
Outside utility is zero. Period-two utility uses the most recent purchase $h$, while the firm's prices can retain $a$ as additional information. Define
\[
w_r(a,h)=\sum_{\ell\in\{j,k\}}s_{r\ell2}(a,h)[p_{\ell2}(a,h)-c_\ell].
\]
Value per arriving consumer is
\[
\pi_r(P)=\sum_a\mu_a\sum_{h\in\{j,k\}}s_{rh1}(a)
[p_{h1}(a)-c_h+\delta w_r(a,h)].
\]
The common policy maximizes $q\pi_H(P)+(1-q)\pi_L(P)$, with $q=\Pr(H)$. Observed-type menus optimize each type separately, using the same cost and initial-state assumptions. There is no additional signal, classifier, targeting cost, or learning intervention.
\section{Induction and harvesting}
For known type, interior terminal prices satisfy
\[
p_{r\ell2}(h)-c_\ell=-\frac{1}{\alpha s_{r02}(h)}.
\]
Product margins are equal at each terminal history. Thus the maintained higher-margin destination of the former coupon exercise does not apply. At an interior first-period optimum,
\[
p_{rh1}(a)-c_h+\delta w_r(a,h)=-\frac{1}{\alpha s_{r01}(a)}.
\]
The continuation value acts as a reduction in effective cost. Higher continuation value supports a lower current margin, holding the common effective margin fixed. These known-type equations must not be applied to pooled shares under unobserved heterogeneity.

Report current profit $A_r$, undiscounted terminal profit $B_r$ per arriving consumer, and total value $A_r+\delta B_r$. Terminal profit includes first-period survival. Profit per survivor divides $B_r$ by its survival probability. For the known-type benchmark, induction sacrifice is the optimized one-period profit minus dynamic current profit; it measures current earnings forgone to support continuation, not a causal coupon effect.

\[
F(v)=\tfrac12\mathbf1\{\pi_H(P^*)\leq v\}+\tfrac12\mathbf1\{\pi_L(P^*)\leq v\}.

\section{Numerical verification and reproducibility}
Known-type prices use the backward interior equations. Heterogeneous common menus use three unconstrained BFGS starts per initial state with analytic gradients and a maximum-gradient acceptance threshold of $2\times10^{-6}$. Multistart optimization provides numerical evidence rather than a global theorem. Tests check finite-difference gradients, initial-state switching, exit accounting, known-type price conditions, information dominance, and comparison with independent derivative-free optimization.

Run the root model, figure builder, and tests as documented in \texttt{toy\_sol.md}. Decomposition data are in \texttt{gamma\_H\_sweep.csv}; the expected-value atoms are in \texttt{value\_distribution.csv}. Both are in \texttt{results/}. Historical coupon/newborn outputs are not inputs to this exercise.
